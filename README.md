# 机场链接管理器（增强版）

卡通风格的 Windows 机场订阅管理工具：订阅有效性检测、到期与流量信息、节点列表、失效标记、代理检测、多种排序方式。单文件 EXE，免安装。

## 功能

- **订阅检测**：直连优先，遇到网络类失败自动改用代理重试；记住需要代理的链接，下次优先走代理。
- **失效标记**：手动 🚫 / 系统 🤖 两种红色「已失效」徽标；检测恢复正常后自动解除标记并回到原分组。
- **排列方式**：默认排序、名称、已失效优先、正常优先、添加时间、流量大小；分组或数值相同时，后添加的排在前面。
- **卡片信息**：自动显示套餐流量与到期日期（月-日），「可复购」开关点击切换并保存。
- **订阅详情**：每个字段都有「📋 复制」按钮；详情区限高滚动，节点信息列表占满剩余空间。
- **分组管理**：新建 / 重命名 / 删除分组，支持右键菜单。
- **全部检测**：可见进度与完成统计，修复原版检测结果保存中断的问题。
- **无边框界面**：任务栏图标支持最小化 / 还原。

## 下载

到 **Releases** 下载 `机场链接管理器.exe`（Windows 10 / 11，x64）。

## 数据位置

订阅数据保存在程序所在目录的 `data/subscriptions.json`（首次运行自动生成）。
本仓库不包含任何订阅数据或账号信息。

## 构建

需要 Python 3.12 x64 与 PySide6：

```bash
pip install pyinstaller pyside6 requests pysocks pyyaml cryptography
cd patchbuild
pyinstaller --noconfirm build.spec
```

产物：`patchbuild/dist/机场链接管理器.exe`
